# 전기패스

PDF 예상문제 기반 개인 학습 웹앱. React + TypeScript + Vite, IndexedDB(Dexie) 사용.

```sh
npm install
npm run dev
```

터미널의 로컬 주소로 접속하세요. `npm run build`로 배포용 빌드, `npm test`로 데이터 및 채점 검증을 실행합니다.

## 포함 기능

- 문제·답안 PDF 9개를 6개 문제집으로 병합, 180문항 (OX 30 / 단답형 30 / 객관식 120)
- 정답 180문항, 해설 155문항 (스캔 답안의 원문 해설 요약 30문항 포함)
- 랜덤·문제집별·오답·즐겨찾기 풀이, 해설/실전 모드
- 단답형 직접 평가, 미등록 정답은 채점 제외
- 진행 중 풀이 이어가기, 일별 풀이 수·정답률
- IndexedDB 자동 저장, JSON 백업 내보내기·가져오기

## 데이터

`src/questions.json`은 `scripts/extract_questions.py`로 PDF에서 추출합니다 (`pypdf` 필요). 정답은 원문 그대로 수록하며 법규·기술 내용의 정확성이나 최신성을 별도로 인증하지 않습니다. 파일명에서 `(답안)`을 제외한 이름이 같은 PDF를 한 문제집으로 연결합니다. `(답안포함).pdf`는 문제편과 정답·해설편을 분리해 한 문제집으로 등록하며, 분리 파일에서 통합 파일로 바뀌어도 기존 문항 ID를 유지합니다. 배관·배선 예상문제1 답안은 6번 상세 해설 도중에 끝나므로 정답 30개와 완전한 해설 5개만 반영합니다. 배관·배선 예상문제2의 14번은 빠른 정답표(③)와 상세 해설(④)이 달라 정답 확인 필요로 표시하고 채점에서 제외합니다. 접지·수변전 예상문제2 답안은 스캔 PDF이며 7쪽을 시각 확인해 정답을 전사하고 해설을 요약했습니다. `scripts/scanned-answers.json`에 파일 해시와 판독 결과가 있으며 원본 변경 시 재검토가 필요합니다. 해설을 임의 생성하지 않습니다. 기존 문제집의 ID는 유지하고, 없어진 문제의 학습 이력은 보존합니다. 문제 순서·보기 수·정답표와의 일치를 자동 검증합니다.

원본 PDF는 로컬의 `data/` 폴더에 보관하며 Git과 배포 결과에는 포함하지 않습니다. 웹앱은 `src/questions.json`에 추출된 문제·정답·해설만 제공합니다.

기록은 해당 브라우저에만 저장됩니다. 로그인·서버 동기화·AI 채점·빈출 분석은 포함하지 않습니다. 실전 모드의 단답형은 결과 화면에서 직접 평가합니다. 오답 복습은 각 문항의 마지막 채점 결과를 기준으로 합니다. 미채점 문항은 정답률 분모에서 제외합니다.

데이터 갱신: `python scripts/extract_questions.py` 실행 후 `npm test` 및 `npm run build`로 검증합니다.
